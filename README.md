# Couch to Tri

A installable, offline-capable web app for a 16-month (70-week) training plan
that goes from couch to a full-distance Ironman triathlon — with Sprint,
Olympic, and Half-Iron triathlons as benchmark races along the way.

No backend, no build step, no account. Your start date, checked-off workouts,
logged times/distances, and personal bests are stored locally on your phone
(`localStorage`); nothing is sent anywhere.

## Run it locally

```
npx http-server -c-1 .
```

Then open the printed `http://127.0.0.1:.../index.html` URL.

## Put it on your phone's Home Screen

The simplest path is GitHub Pages, since this already lives in a GitHub repo:

1. On GitHub: **Settings → Pages → Source → Deploy from a branch**, pick this
   branch and the `/ (root)` folder, save.
2. Visit the published URL on your phone.
3. **iPhone/iPad (Safari):** tap the Share icon → "Add to Home Screen".
   **Android (Chrome):** tap the ⋮ menu → "Add to Home screen" / "Install app".

The Settings tab inside the app repeats these instructions and will show a
one-tap **Install App** button on Android/Chrome when the browser offers it.

Once installed, a service worker caches the whole app (HTML/CSS/JS + the plan
data + icons), so it keeps working with no signal — at the pool, on the
bike, wherever.

## How the plan is structured

The plan is generated by [`tools/generate_plan.py`](tools/generate_plan.py)
into [`data/plan.json`](data/plan.json), which the app reads at runtime.
Six phases, each one calendar quarter (13 weeks) except the final taper
month (5 weeks) — 70 weeks / 16 months total:

| Phase | Weeks | Months | Milestone |
|---|---|---|---|
| A. Foundation | 1–13 | 1–3 | — |
| B. Sprint Build | 14–26 | 4–6 | 🏁 Sprint Triathlon |
| C. Olympic Build | 27–39 | 7–9 | 🏁 Olympic Triathlon |
| D. Half-Iron Build | 40–52 | 10–12 | 🏁 Half-Iron (70.3) |
| E. Ironman Build | 53–65 | 13–15 | — (peak volume) |
| F. Taper & Race | 66–70 | 16 | 🥇 Full Ironman (140.6) |

Within phases A–E, every 4th week is a recovery ("cutback") week — volume
drops ~25% so the previous three weeks of build get absorbed. Phase F is a
hand-authored taper, not generated by the interpolation formulas.

To tweak the plan (different target race, more/fewer weekly sessions,
different volume targets), edit the phase functions in `generate_plan.py`
and re-run:

```
python3 tools/generate_plan.py
```

## Regenerating the icons

Icons are rendered from an HTML/CSS badge via headless Chromium (no image
editor needed):

```
NODE_PATH=/opt/node22/lib/node_modules node tools/generate_icons.js
```

## App structure

- `index.html`, `css/styles.css`, `js/app.js` — the app shell (vanilla JS,
  no framework, no dependencies)
- `manifest.json`, `service-worker.js` — PWA install + offline support
- `data/plan.json` — the generated 70-week schedule
- `icons/` — home screen icons (192/512/maskable/apple-touch)
- `tools/` — the plan and icon generator scripts (not needed at runtime)
